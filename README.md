## 🌟 نظرة عامة (Overview)

تطبيق **صحبة (Suhbah)** تم بناؤه بعناية فائقة لتقديم تجربة إيمانية متكاملة وسلسة بدون إعلانات مزعجة وبأداء سريع جداً. يعتمد التطبيق على معمارية **Clean Architecture** ونمط إدارة الحالة **BLoC / Cubit** لضمان فصل المهام وقابلية التوسع والصيانة العالية، مع دعم كامل للعمل بدون إنترنت (Offline-First) في الأقسام الحيوية كالأذكار والمصحف الشريف.

## ✨ المميزات الرئيسية (Key Features)

### 1. 🌟 شاشة بداية سينمائية وحواف كاملة (Edge-to-Edge Splash Screen)
- **تصميم إسلامي دافئ وأصيل**: لوحة فنية إسلامية صافية عالية الدقة تجمع بين ظلال المساجد، الكثبان الرملية، شروق النور، وأغصان الزيتون المباركة.
- **حركة إيمانية متناسقة (Staggered Motion)**:
  - ميدالية دائرية مركزية ذهبية مع هالة نورانية تتنفس بنعومة (`_MedallionAuraPainter`).
  - ذرات نور ذهبية عائمة في الأجواء بحسابات فيزيائية دقيقة (`GoldenParticlesPainter`).
  - ظهور تدريجي فخم لشعار التطبيق وبطاقة الآية الكريمة: *(وَاذْكُر رَّبَّكَ فِي نَفْسِكَ تَضَرُّعًا وَخِيفَةً)* [الأعراف: 205].
  - مؤشر تحميل دائري ثنائي الألوان إسلامي فاخر يدور بسلاسة.
- **دعم حقيقي لكامل الشاشة (True Edge-to-Edge)**:
  - معالجة متقدمة لـ Android 10 حتى Android 15+ وإلغاء فرض التباين الإجباري (`enforceNavigationBarContrast = false`).
  - شفافية كاملة لشريط الحالة (Status Bar) وشريط التنقل السفلي (Navigation Bar) بدون أي مستطيل أو شريط أبيض خلف أزرار التحكم.

### 2. 📖 المصحف الشريف والقرآن الكريم (Holy Quran & Mushaf Reader)
- **وضعان للقراءة**:
  - **وضع القراءة الحديث (Reading Mode)**: بطاقات آيات دائرية وتفاعلية مع إمكانية مشاركة الآية كبطاقة نصية أو صورة إسلامية فاخرة (`ayah_share_card`).
  - **وضع المصحف الحقيقي (Mushaf Mode)**: محاكاة دقيقة لصفحات مصحف المدينة المنورة مع أرقام الصفحات وفواصل السور والخرطوشة السفلية المعتمدة (`mushaf_bottom_cartouche`).
- **تلاوة صوتية متواصلة (Audio Recitation)**:
  - استماع متواصل للقرآن الكريم بصوت القارئ الشيخ مشاري بن راشد العفاسي.
  - تشغيل في الخلفية مع شريط إشعارات للتحكم (`RadioService` و `AudioService`).
  - تمييز الآية الحالية أثناء الاستماع تلقائياً والتنقل الذكي للآية التالية.
- **فهرس متقدم وحفظ موضع القراءة**:
  - تصنيف حسب السور، الأجزاء، والأحزاب مع حفظ آخر موضع قراءة محلياً والعودة إليه بنقرة واحدة.

### 3. 📿 الأذكار اليومية والأدعية بدون إنترنت (Offline-First Azkar & Duaa)
- **أداء فائق بدون إنترنت**: تحميل محلي فوري من ملفات الـ Assets دون الحاجة للاتصال بالشبكة (`AzkarRepo`).
- **أذكار المسلم الشاملة**: (أذكار الصباح، أذكار المساء، أذكار الاستيقاظ، أذكار النوم، أذكار بعد الصلاة، وتسابيح متنوعة).
- **عداد تفاعلي ذكي**: عداد دائري تفاعلي مع ردود فعل لمسية (Haptic Feedback) وإحصائيات بعدد مرات التكرار المتبقية.
- **أدعية قرآنية ونبوية مصنفة**: واجهة نظيفة وسلسة مصنفة حسب المناسبات بدون تشويش.

### 4. 🕋 مواقيت الصلاة والقبلة ثلاثية الأبعاد (Prayer Times & 3D Qibla)
- **مواقيت صلاة دقيقة**: حساب مواقيت الصلاة حسب موقع الجهاز الجغرافي بالاعتماد على أدق الطرق الفلكية.
- **العد التنازلي للصلاة القادمة**: بطاقة بارزة تعرض الوقت المتبقي بالألوان المميزة لكل وقت.
- **بوصلة القبلة التفاعلية**: توجيه دقيق نحو الكعبة المشرفة مدعوم بحساسات الجهاز ومؤشر مرئي ثلاثي الأبعاد.

### 5. 📜 مخطط الختمة القرآنية التفاعلي (Khatmah Planner)
- **تخطيط مرن**: إعداد ختمة مخصصة وتحديد مدتها وعدد الصفحات اليومية.
- **خريطة تفاعلية للختمة (Khatmah Interactive Map)**: متابعة مرئية لتقدم القراءة عبر أجزاء القرآن الكريم الثلاثين.
- **دعاء ختم القرآن**: زر مباشر للانتقال إلى دعاء الختم المأثور عند اكتمال الختمة المباركة.

### 6. 📿 السبحة الإلكترونية المتطورة (Interactive Digital Sibha)
- **محاكاة واقعية لحبات المسبحة**: رسم فيزيائي ناعم لحبات السبحة مع تمايلها أثناء التسبيح (`bead_string_painter`).
- **خيارات الأذكار والدورات**: اختيار الذكر، تحديد دورات التسبيح (33، 99، أو حر)، وقائمة سفلية مخصصة لإعادة التعيين.

### 7. 🌙 صيام التطوع وتتبع السنن الرواتب (Fasting & Sunan Tracker)
- **تتبع سنن الصلوات**: جدول مخصص لتوثيق صلوات السنن الرواتب، صلاة الضحى، وقيام الليل.
- **أيام الصيام المسنونة**: تنبيه ومتابعة صيام الإثنين والخميس والأيام البيض.

### 8. 📻 إذاعة القرآن الكريم المباشرة (Live Quran Radio)
- بث حي ومستمر لإذاعات القرآن الكريم الرائدة (إذاعة القاهرة، مكة المكرمة، والإذاعات الدولية).
- تشغيل في الخلفية مع دعم الاستئناف والإيقاف التلقائي عند المكالمات.

## 🏗 معمارية النظام (Clean Architecture)

تم تقسيم المشروع وفق أفضل ممارسات **Clean Architecture**:

```
lib/
├── core/                               # الخدمات العامة والأساسيات
│   ├── app/                            # ويدجت التطبيق وإدارة الثيم (MyApp)
│   ├── constants/                      # الثوابت، الألوان، ومسارات الوسائط (AssetsData)
│   ├── errors/                         # معالجة الأخطاء والـ Failures
│   ├── initialization/                 # تهيئة الخدمات ومزامنة البيانات (AppInitializer)
│   ├── routes/                         # توجيه الشاشات باستخدام GoRouter
│   ├── theme/                          # لوحة الألوان الفاتحة والداكنة
│   └── utils/                          # حقن الاعتماديات (GetIt Service Locator)
│
├── features/                           # وحدات الميزات المستقلة
│   ├── app/                            # شاشة البداية والتحكم العام
│   ├── azkar/                          # إدارة وعرض الأذكار (Offline-First)
│   ├── calendar/                       # التقويم الهجري والمناسبات
│   ├── duaa/                           # موسوعة الأدعية
│   ├── fasting/                        # سنن الصلاة وصيام التطوع
│   ├── hadith/                         # الأحاديث النبوية الشريفة
│   ├── home/                           # الشاشة الرئيسية والبطاقات التفاعلية
│   ├── khatmah/                        # مخطط الختمة القرآنية والخريطة التفاعلية
│   ├── notifications/                  # إشعارات الصلاة والأذكار
│   ├── prayer_times/                   # حساب المواقيت وتنبيهات الأذان
│   ├── qibla/                          # بوصلة تحديد اتجاه القبلة
│   ├── quran/                          # المصحف، التلاوات الصوتية، والبحث
│   ├── settings/                       # إعدادات المظهر، التنبيهات، واللغات
│   └── sibha/                          # السبحة الإلكترونية التفاعلية
│
└── main.dart                           # نقطة انطلاق التطبيق وضبط الـ Edge-to-Edge
```

## 📱 شاشة البداية وحواف الشاشة (Edge-to-Edge)

تم حل مشكلة المستطيل الأبيض والـ Scrim التلقائي خلف شريط الأندرويد السفلي وفق أعلى المعايير الهندسية:

1. **إلغاء فرض التباين بنظام أندرويد 10+ و 15+**:
   - إضافة ملف النمط [android/app/src/main/res/values-v29/styles.xml](file:///home/seg/Downloads/suhbah-last-update/android/app/src/main/res/values-v29/styles.xml) وضبط:
     ```xml
     <item name="android:enforceNavigationBarContrast">false</item>
     <item name="android:enforceStatusBarContrast">false</item>
     ```
2. **برمجة نافذة النظام في Kotlin**:
   - في [MainActivity.kt](file:///home/seg/Downloads/suhbah-last-update/android/app/src/main/kotlin/com/example/islamic_app/MainActivity.kt):
     ```kotlin
     WindowCompat.setDecorFitsSystemWindows(window, false)
     if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.Q) {
         window.isNavigationBarContrastEnforced = false
         window.isStatusBarContrastEnforced = false
     }
     ```
3. **تكوين `SystemChrome` في Flutter**:
   - تفعيل `SystemUiMode.edgeToEdge` في `main.dart` و `splash_screen.dart` مع تمرير:
     ```dart
     systemNavigationBarContrastEnforced: false,
     systemStatusBarContrastEnforced: false,
     systemNavigationBarColor: Colors.transparent,
     statusBarColor: Colors.transparent,
     ```

## 🛠 التقنيات والمكتبات المستخدمة (Tech Stack)

- **UI Framework:** Flutter 3.9.2+ (Dart 3)
- **State Management:** `flutter_bloc` (^8.1.6)
- **Dependency Injection:** `get_it` (^7.6.7)
- **Navigation:** `go_router` (^14.7.0)
- **Audio & Media:** `audio_service` (^0.18.18), `just_audio` / `ExoPlayer`

- **Maps:** `google_maps_flutter` (^2.13.1)
- **Networking:** `dio` (^5.7.0)

## 🚀 دليل التشغيل والتثبيت (Getting Started)

### المتطلبات الأساسية
- Flutter SDK (الإصدار 3.9 أو أحدث)
- Android Studio / VS Code
- جهاز محمول أو محاكي أندرويد (API 29+ موصى به)

### التثبيت والتشغيل
```bash
# 1. استنساخ المستودع
git clone https://github.com/Omar-Shemais/Suhba.git
cd Suhba

# 2. تثبيت الحزم والمكتبات
flutter pub get

# 3. تشغيل التطبيق في بيئة التطوير
flutter run

# 4. بناء نسخة الإنتاج (Release APK)
flutter build apk --release
```

## 📝 سجل التغييرات v1.0.2+8

- **شاشة بداية أصلية جديدة**: إعادة بناء شاشة البداية باستخدام الصورة الأصلية الصافية للمسجد والكثبان الرملية والميدالية الذهبية.

- **تحسين سرعة الأذكار**: جعل الأذكار تعمل بالكامل Offline-First بسرعة استجابة لحظية.
- **تحديث رقم الإصدار**: ترقية الإصدار إلى `1.0.2+8`.
- **توثيق كامل للاختبارات والمعايير**: إضافة اختبارات آلية جديدة تغطي معمارية النظام بالكامل.
